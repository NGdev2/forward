# Forward

An endless-road RPG runner for phones. The hero runs down a road; three lanes open ahead
(monsters, chests, campfires, shrines, traders, the unknown); you pick one. Fights are
turn-based with a timed parry, six equipment slots with random affixes, six relic sets with
2/4-piece bonuses, talents, twenty scripted bosses and twelve biomes. Everything is procedural:
no image or audio assets ship — characters are vector rigs on Canvas 2D and the music and SFX
are synthesised with WebAudio. Fully offline. English and French.

Built with Vite + TypeScript, plain DOM/CSS for UI, `<canvas>` for the world and fights, and
Capacitor for the Android wrapper.

## Develop

```bash
npm install
npm run dev          # http://localhost:5173, in DEV `window.__game` is the GameContext
npm run build        # -> dist/
npm run sim          # headless combat balance simulator (see scripts/BALANCE.md)
npm run i18n:check   # EN/FR key completeness (must print "i18n check: OK")
npx tsc --noEmit
```

Player feedback rounds live in `feedback.md`; each round is treated as the spec.

### Code map

- `src/core` — screen manager (single RAF loop; screens are singletons that reset in `mount()`) and the `GameContext` contract.
- `src/game` — state & save migration, combat engine (`combat.ts`, two-phase rounds with parry), loot/affixes, encounters, content tables under `data/`.
- `src/screens` — title, run (road + lanes), combat (arena, QTE, fight log), reward (the only place rewards are applied), inventory, shop.
- `src/render` — hero and creature rigs, particle/element FX, SFX, procedural music.
- `src/i18n` — `t()`, plurals, id-keyed content names; `en.ts` / `fr.ts`.
- `src/styles/tokens.css` — design tokens; screens never hard-code colours.

## Android

Requirements on the build machine: JDK 17, Android SDK with platform 35 (`ANDROID_HOME`).
`android/` is generated by Capacitor and is git-ignored; recreate it with `npx cap add android`
if missing, then re-apply `android/variables.gradle` (targetSdk 35) and the icons under
`android/app/src/main/res` (render them with the icon script in the session notes, or copy
from a previous checkout).

```bash
npm run android:debug            # debug APK -> android/app/build/outputs/apk/debug/
./scripts/android-release.sh keystore   # once: create the upload keystore (back it up!)
npm run android:release          # signed AAB -> android/app/build/outputs/bundle/release/
```

## Publishing to Google Play — checklist

- Application id is `com.ngdev.forward` (`capacitor.config.ts` + `android/app/build.gradle`).
  It is permanent after the first upload; change it before then if you want another.
- `targetSdkVersion` 35 (`android/variables.gradle`) — Play raises the floor every August.
- Upload a **signed AAB** built with `npm run android:release`, bump `versionCode` in
  `android/app/build.gradle` for every upload.
- Store assets: `store/listing-en.md`, `store/listing-fr.md` (texts), a 512×512 icon and a
  1024×500 feature graphic (rendered by the icon script), phone screenshots from a device.
- Privacy policy: host `store/privacy-policy.md` at a public URL and link it in the Console.
- Content rating questionnaire (fantasy violence), data safety form (no data collected).
- New personal developer accounts must run a 14-day closed test with 12 testers before
  production access.
- Monetisation surfaces (rewarded-ad buttons, gem packs, support tiers) are labelled
  placeholders and charge nothing. Wire real SDKs or hide them before release.
